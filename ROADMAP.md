# Roadmap

1. Add rate-limited adapters for PubMed, Crossref, OpenAlex, Europe PMC, and ClinicalTrials.gov.
2. Add validated entity resolution for genes, proteins, pathways, biomarkers, and interventions.
3. Persist evidence and graph relationships in PostgreSQL with migration tooling.
4. Add reproducible notebooks and independent scientific review workflows.
5. Add optional vector and graph backends with documented privacy and licensing controls.
