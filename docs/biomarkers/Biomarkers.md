# Biomarker framework

The catalog covers epigenetic, proteomic, transcriptomic, metabolomic, inflammatory, immune, mitochondrial, cellular-senescence, and telomere-related measurements. Each entry records what is measured, relevance, maturity, and limitations. A biomarker is never presented as a definitive measure of biological age.
